# Code of Conduct

## Professional Standard

This organisation builds software that can trigger containment actions on production infrastructure. Treat every discussion, issue, and pull request as professional work with real operational consequences.

## Expected Behaviour

- Be precise, technical, and respectful.
- Disagree on implementation details, not on personal attributes.
- Provide evidence for claims, especially security claims.
- Report mistakes quickly. Silent failure is worse than visible failure.

## Unacceptable Behaviour

- Harassment, abuse, threats, or personal attacks.
- Intentionally misleading security guidance.
- Sharing secrets, customer data, or sensitive operational details.
- Repeated low-effort spam in issues or pull requests.

## Enforcement

Maintainers may edit, lock, or remove content and restrict participation when conduct degrades the safety or usefulness of the project.

For security-sensitive concerns, contact security@vyrox.dev.
